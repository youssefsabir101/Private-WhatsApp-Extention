# Privacy Policy — Private WhatsApp

**Last updated: October 30, 2026**

Private WhatsApp is an independent browser extension developed by Youssef Sabir. It provides visual privacy controls for WhatsApp Web.

## 1. Information Collection

Private WhatsApp does not intentionally collect personal information through the functionality described in this policy.

The reviewed extension scripts do not contain analytics, advertising trackers, or requests to external servers.

## 2. Local Data Storage

The extension uses the browser's local extension storage to save settings and preferences, including:

- Privacy protection status
- Blur strength
- Sidebar visibility
- Silent mode preference
- Automatic lock settings
- PIN hash and salt
- Dynamic Island position
- Lock status

This information is stored locally using the browser extension storage API.

## 3. PIN Protection

When a user creates a PIN, the extension stores a SHA-256 hash and a randomly generated salt instead of storing the PIN as plain text.

The PIN feature provides an additional visual privacy layer. It is not encryption and should not be considered a replacement for device or account security.

## 4. WhatsApp Web Access

Private WhatsApp operates on:

`https://web.whatsapp.com/`

It modifies the page interface to provide visual privacy features. It is not designed to transmit conversations, messages, or contacts to the developer.

## 5. Data Sharing

The extension does not intentionally sell or share locally stored settings with advertisers or analytics providers.

## 6. Data Control

Users can remove locally stored extension data by uninstalling the extension or clearing its stored browser extension data.
